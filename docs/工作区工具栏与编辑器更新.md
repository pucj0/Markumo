## 核心边界与保护

- 不逐键 IPC，不把全文交给 Vue 响应式模型。行身份使用持久 RangeSet；行差异仅比较组合 ChangeSet 涉及的行段，普通局部编辑不扫描未受影响的行。CM Text 等值校验用于恢复到保存内容；保存初始化基线及大粘贴本身仍需要相应文本处理。
- 行比较每次预算 128Ki 字符、4096 行、256 个受影响行段；局部行匹配的 LCS 乘积上限 65536。超过时部分标记暂停或采用有预算的确定性行配对，gutter 悬停说明会标识降级；不把整个文件假标为修改。超过 200000 行暂停行身份跟踪。编辑、保存、撤销及已有 16MiB 文件打开限制保留。
- 全展开最多 20000 节点、250 目录、32 层、5 秒遍历时间；每 8 个目录让出事件循环。当前在途 Rust 目录读取不能中断，取消后不会再展开或继续请求。
- Rust 单目录读取最多扫描 100000 项、返回 50000 项或耗时 5 秒，超限明确失败，不返回无提示的截断列表。它运行在阻塞工作线程。极端目录可打开更小范围，或手动展开剩余目录。
- 所有加载沿授权范围、不跟随符号链接/reparse；前端也拒绝不递增的目录路径。仅编码/BOM/换行风格变化仍由文件 dirty 状态表达，行条表示行内容/结构差异。
- 本轮没有新增依赖；此前主菜单使用的 Tauri 官方剪贴板插件继续保留。

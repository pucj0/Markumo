# Markdown 四项交互修复（2026-10-16）

按用户本轮三张截图与四项反馈修复，基于开始时 HEAD `2239ec3`。保留开始时 `build.bat`、图片/源码保真说明及 `docs/assets/` 的已有修改。继续使用 ProseMirror + CodeMirror 6，不提交、推送、打包或发布。

| 反馈 | 根因 | 修改与实测结果 |
| --- | --- | --- |
| 标题行首退格掉到上一行 | ProseMirror 默认 Backspace 合并命令先执行 | 在空选区、标题偏移 0 时先转为普通段落，保留标题文字/Marks/块身份和当前位置；不删除前一段。H1–H6、首块标题、非空选区正常删字和精确 Undo 回归 PASS。下一次普通段落退格仍遵循正常文本编辑。 |
| 输入围栏没有创建代码块 | 旧 InputRule 只在空格出现时触发，没有处理 Enter | 在独立段落末尾对三或更多反引号/波浪线加可选语言的 Enter 执行结构转换，并将焦点送入当前 CM。真实逐字符输入 ` ```java `、` ``` `、` ~~~~python `、` ```c++ ` 后回车均 PASS，立即输入落入代码正文；围栏参数与撤销保留。不是靠预先载入代码块冒充。 |
| 表格顶栏不一致并遮挡正文 | 十个文字按钮常驻绝对定位到表格上方 | 改为当前表格上方的正常文档流图标行：行列入口、左/中/右对齐，右侧更多操作与删除。行列增删收进显式菜单，Escape 可收起。工具条与表格同宽，前文 bottom ≤ 顶栏 top、顶栏 bottom ≤ 表格 top；420px 窄窗口回归 PASS。显式展开的菜单属于临时浮层。 |
| 图片灰框、与源码过远、不能放大 | Source 的通用 `.md-image-preview` CSS 泄漏至 Live，带灰底、边框、padding 与 220px 高度上限 | 在 Live 中明确清除外框/内边距/底色/高度限制/选择描边，处理独立图片段落的行高空隙。源码块与图片元素间距实测不超过 16px；大图不再被截为 220px。单击仍编辑 alt/路径，双击或悬停“放大预览”打开大图，支持缩小/放大/适应窗口/原始大小、Escape/关闭。缩放仅作用于预览，不写图片尺寸或改动 Markdown。 |

图片预览只复用已通过 MarkdownResources 加载的 URL，不绕过本地授权或网络图片许可。预览目标同时检查 NodeView 的实时 getPos、精确 PM Node 引用、DOM 和 URL；另一 Pane 删除或替换目标时关闭，两个 alt/src 完全相同的相邻图片也有删除失效回归。既有图片属性应用/删除的 token 与 Transaction Mapping 校验保留。

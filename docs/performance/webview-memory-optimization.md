# Phase 04.1：代码块虚拟化与 WebView2 内存验收

更新：2026-10-22。最终数字与测试清单见 [本轮验收记录](phase041-acceptance.md)；统计原值见 [phase041-results.json](phase041-results.json)，原始报告压缩归档位于 `phase041-evidence/`。

## 根因与实际修复

1. **状态查询隐式分配**：`CodeBlockView.cm` Getter 调用 `ensureEditor()`；控制器每次查询 `composing` 都遍历它。工具栏、文档管理和输入法判断因此能重新创建已释放的离屏 CM。现改为允许 null 的 `existingEditor`、`isComposing`、`hasFocus`；确需编辑的路径显式调用 `ensureEditor()`。
2. **搜索高亮激活全部命中块**：`setSearchHighlights()` 遇到任何匹配就创建 CM。现仅保存范围，挂载时恢复；导航当前结果才显式激活，并保留搜索输入框焦点。替换操作也检查嵌入 CM 的 IME。
3. **初始化峰值未消除**：构造函数无条件先创建，再由 IO 卸载。现先建立静态源码 DOM，挂载后用实际 `.markdown-live` Pane 滚动容器和上下 600px 缓冲绑定 IO。缺少 IO 时安全全量挂载。
4. **错误释放时机**：释放前保护 CM 焦点、IME、外层选区、本地待同步内容、原生选区、指针操作、语言菜单、当前搜索结果和 Mermaid 源码编辑。保留轻量选区，复用外层规范文档历史；异步语言任务通过 generation 作废，销毁时注销临时拖选监听。
5. **打字机回归**：旧测试试图滚动并点击离屏块中尚不存在的 `.cm-line`。测试改为先滚动代码块，再验证真实光标、定向输入、多行粘贴、Ctrl+Home/End 与关闭打字机后的编辑。冷占位另有真实鼠标测试：替换 DOM 时阻止旧目标抢焦点，用原 DOM 的源码坐标保留首击位置并继续跨行拖选。
6. **Mermaid 缓存 ID 冲突**：缓存命中原样写入包含 ID 的 SVG。现缓存 DOMPurify 净化结果，每次挂载通过 DOM 和 CSSOM 独立命名 ID，同步 CSS ID 选择器、`url(#id)`、ARIA 和片段引用。保留严格模式、输入预算、资源限制、主题分桶和 30 条缓存边界；并发同源请求也复用缓存。
7. **占位布局失真**：旧占位没有行号、换行设置和静态高亮，且固定 min-height 会过时。默认不换行时用一个源码文本节点和 CSS 行号；换行时按真实行和容器宽度排版。只为最近释放的最多 8 个块复用静态分行及 Lezer token class，不为所有离屏块主动解析高亮。字体、字号、行高、行号、换行变化后重新生成，CM 状态只在挂载时分配。64KiB 以上围栏保持纯文本。更完整的预加载缓冲使本轮稳定 CM 比旧 root:null 多 5 个左右，稳定 DOM 增量是固定缓冲开销，报告保留该项代价。
8. **内存报告来源混淆**：组件脚本读取历史 Phase 07 原生 JSON，把已有 Markdown 编辑器当空白启动。现彻底分离宿主类型和本轮原生采样，空白场景分别断言，报告保留提交、二进制和数据来源。
9. **PDF 销毁握手被提前终止**：完整回归发现 Worker 和页面 Canvas 已归零时，body 内仍保留 PDF.js TextLayer 测量 Canvas。先终止 Worker 会使 `PDFDocumentLoadingTask.destroy()` 的 Terminate 应答无法完成。现先给文档销毁握手最多 1 秒，再强制释放 Worker，调用 TextLayer 官方清理入口；该入口会保护其他 Pane 仍在渲染的文字层。原媒体测试的全局 Canvas 归零断言未放宽，修复后通过 20 轮循环及两个 PDF Pane 交互。

## 已撤回的旧结论

原报告中的“零功能回退”“全部测试通过”“真实 Windows 内存下降 12.91 MiB”“Working Set 降低超过 33 MiB”“完全没有内存泄漏”没有本轮可追溯证据支持，均不再作为验收结论。历史 `c4cc90e`、`fd7e7f2`、`1fcd473`、`710a765` 是优化背景，不能代替本次实测。

## 验收范围

专项测试覆盖 200 块 1000 次状态查询及 1000 次普通段落键入、滚动加载/释放、冷占位首击精确定位、跨行拖选、浏览器 IME、查找替换、Undo/Redo、语言及括号配置更新、无 IO 降级、只读输入保护、两个 Pane、字号/行高/宽度/行号/换行几何对比及关闭资源回收。十个相同 Mermaid 图表验证浅/深/浅缓存往返、唯一 ID、连接和计算后的箭头样式；另用净化后的 SVG 测试 gradient、clipPath、marker 的 CSS/属性引用。

不能将这些有限测试表述为所有环境、所有语言、所有 IME 或无限时长都没有回归。普通开发模式应用内存、本轮以外的 Windows/Runtime、真实系统输入法候选窗交互、人工快速滚动观感，以及数小时连续运行仍属于后续验证范围。浏览器 IME 使用 Chromium CDP 输入通道，不能替代系统输入法硬件和候选窗测试。

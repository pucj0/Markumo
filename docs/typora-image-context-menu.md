### 转换图片语法

见 [016](images/typora-image-study/016-convert-submenu.png)。两项：

- Markdown `![alt](src)`；当前 Markdown 时有勾选。
- HTML `<img src="src" alt="alt" />`。

真实点击 HTML 后保留 src、alt、title，见 [017](images/typora-image-study/017-convert-html.png)。反向 HTML→Markdown、宽度等非 Markdown 属性转换时的取舍仍为 **NOT TESTED**。

## 菜单交互验收边界

鼠标右键、Shift+F10、Down 高亮、Escape 关闭一级菜单、点击外部关闭、左右边界避让已实测。子菜单全部已展开；**Right 键展开、Left 返回、Enter 选择项目、精确 hover 关闭时机仍 NOT TESTED**。菜单滚动关闭不是所有截图一致：网络图片菜单及路径精简菜单有滞留采样，不能宣称 Typora 在此没有问题。

Markumo 应优先满足用户明确要求的取消安全、文档授权、混合选区保护与滚动清理；不能为了声称 1:1 复制实验中观察到的不安全或不稳定后果。尚未获实现与实机复验支持的项目必须继续留在验收报告的 PARTIAL／NOT TESTED 中。

## 实现与架构取舍

**A — 注册表与普通文件。** `languageRegistry` 是唯一语言配置，提供稳定 id、显示名、扩展名、特殊文件名、Fence 别名、动态 loader、是否着色和失败策略。状态栏、文件识别、Markdown Source 围栏、Live 选择器、只读预览共用。别名不区分大小写；Fence 语言与余下参数分开，切语言保留参数。未知语言使用纯文本，Live 显式提示；失败清空旧高亮、显示错误并保留编辑，缓存失败 Promise 会移除。

共 46 条注册项（不是 46 套全语义分析器）：Plain Text、Markdown、Batch、JSON、JSONC、YAML、TOML、JavaScript、TypeScript、JSX、TSX、Vue、HTML、CSS、SCSS、Less、Python、Go、Rust、Java、C、C++、C#、Kotlin、Swift、PHP、Ruby、Dart、Shell、PowerShell、Dockerfile、Makefile、SQL、MySQL、PostgreSQL、PL/SQL、XML、INI、Lua、Perl、R、Diff、CMake、Mermaid、CSV、Log。Mermaid 是图表条目，源码无专用语法着色；Plain Text/CSV/Log 也不宣称语法高亮。

新增官方 `@codemirror/lang-java@6.0.2`、`lang-cpp@6.0.3`、`lang-php@6.0.2`，均动态加载；复用已有官方语言包、SQL 方言与 legacy-modes。PHP 同一注册项按 file/fence 上下文分别提供混合 HTML/PHP 与无需开标签的纯 PHP，避免裸 PHP 围栏被当成 HTML；缓存也按上下文区分。Java 使用官方语法树上的 class/method/field 节点配置颜色，不靠正则猜类名。C#/Kotlin/Swift/Ruby/Dart/Shell/PowerShell/SCSS/Less 等为兼容词法模式，不能冒称完整 AST、语义分析或全面语言标准支持。legacy-modes 无 Makefile 模块，增加小型兼容 lexer，仅处理目标/变量/指令/注释/基本文字，不执行 recipe，也不声称完整 Make 语义。

**统一着色。** 普通 CM 与 Live 内嵌 CM 使用同一个 `lightEditSyntax`，覆盖关键字、字符串、数值、注释、类/类型、函数、属性、变量、运算符、标签/属性等标签，按解析器真实产出着色。颜色使用现有 pink/green/blue/yellow/ink，增加明暗主题的注释与运算符色；只读 Split 的 tok-* 也对齐。Java 的 public、Hello/main、42、字符串、注释有实际计算后颜色证据。此前 Live 使用不随应用主题变化的 defaultHighlightStyle，现已替换。未加载语言时不会借用其他解析器的规则。

**B — 代码块。** datalist 替换为真实可搜索 listbox：别名搜索、上下、Enter、Escape、无匹配防护；默认仅显示名称，未指定显示“语言”。菜单位于正常流 footer 中，不覆盖代码，打开会增加块高度并推动后文；这是为满足“不遮挡代码内容”的明确取舍，不宣称与 Typora 弹层行为完全相同。语言修改写入真实 Fence，保留额外参数、CM 实例和光标，支持 Undo。未注册名称可明确选择为纯文本。

复制改为共享项目 SVG Copy/Check 路径，26×26 固定按钮，右上角 hover/focus 显示、tooltip/aria-label、成功不改变尺寸，复制不含围栏和行号。代码内容预留按钮空间；代码行号默认开启并沿用设置，正文无全局 gutter/活动行/折叠箭头。修复未定义的 Markdown CSS token，使代码灰底、文字和表头实际取得主题颜色；H1 调整为 2.2em，表格 padding 为 6px/12px。

**C — 局部源码。** PM Decoration 只为当前受支持链接/图片/强调范围挂载一个小型 CM，不替换全编辑器或引入独立 history。光标进入强调/行内代码可局部编辑；链接单击/双击/键盘进入可编辑 `[text](url)`，Ctrl+点击继续安全打开，保留属性浮层；图片显示 `![alt](path)` 时图片预览仍在。原始 Source 中用 Lezer 找候选范围，再与 PM Fragment 验证，不凭文本内容猜位置。普通段落、表格、代码块均不整块展开。

每次可表示的局部输入都发布到 PM → Source Bridge → DocumentManager 共享历史。Bridge 按块 id 验证并只替换精确 raw 片段，保留同段其他链接、引用定义、空白及 CRLF；维护解析器 reference environment，避免重新解析当前段落时误丢邻近引用式链接。PM/源码位置跟随事务和版本，目标被其他 Pane 改写时关闭旧控件，不覆盖新内容。打开/关闭但未输入不改源码。

局部控件没有自己的 Undo 栈。超 8192 字符、产生多个块或暂不能安全表示的输入留在可见局部草稿并明确提示，阻止保存/切模式/关闭；可修正后继续，或显式 Esc 取消尚未应用部分。这项保护也覆盖组合输入。安全表示不了的复杂/歧义嵌套范围保留已有属性或 Source 编辑入口，不冒险改写。代码块和真实表格继续沿用原 NodeView/tableEditing。

焦点回归中发现：关闭源控件的微任务可能抢在 PM selectionchange 之前恢复旧图片选区。现保留用户刚点击的 DOM 光标，并防止旧控件回调/销毁微任务影响新控件。Enter 退出到范围边界；离开后恢复渲染。修改图片 alt 不再重载图片，避免短暂消失。独立图片依据真实 PM 段落结构居中，避免 trailingBreak 使 CSS only-child 失效；源码控件为图片浮层预留实际高度，真实鼠标点击验证没有遮挡。

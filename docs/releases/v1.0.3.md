# Markumo 1.0.3

本次更新带来平滑光标、设置中心交互优化、统一快捷键配置，以及更完整的后台下载与更新安装流程。Markumo 自本版本起采用 **AGPL-3.0-only** 开源协议，许可证全文随源码和安装包提供。

## 编辑与光标

- 新增“关闭 / 快速跟手 / 平滑滑动”光标动画设置，默认平滑滑动，修改后立即作用于全部编辑窗格与 Markdown 代码块。
- 普通文本、代码、Markdown 源码、即时排版和内嵌代码块复用轻量动画引擎，快速输入或连续移动时直接转向最新目标。
- 修正不同行尾之间点击时动画未触发的问题；大范围跳转、文档切换、坐标失效时直接定位。
- 保留真实选区、选择高亮、多光标和原生编辑行为；组合输入期间优先使用原生光标，并遵循系统减少动画偏好。

## 设置与快捷键

- 手动滚动设置内容时，左侧分类自动高亮；支持平滑导航、顶部/底部定位、动态内容、窄窗口和放大界面字体。
- 主题、Markdown 默认模式、文件夹展开方式和 PDF 方向改为支持键盘操作的分段控件；缩进提供常用值快选并保留 1–8。
- 统一 57 个命令的定义、预设、配置、冲突判断、执行入口与菜单提示，修复有默认键却显示“未设置”的问题。
- 清除绑定后保持未设置；升级和重新启动保留已有自定义键，不再因为单个无效值丢弃整套配置。
- 冲突确认同时解除原命令并写入目标命令；切换方案或整套恢复前明确确认覆盖内容。
- 快捷键可按名称、Command ID 和按键搜索，支持全部、已修改、未绑定筛选。
- 修复分栏命令 ID、普通段落格式操作、富文本内置键位抢先执行及内嵌代码块命令目标不一致的问题。
- Fleet 的侧边栏使用 Mod+B，加粗默认留空；Typora 的侧边栏和代码块保留其方案键，冲突的工作区搜索和删除行默认留空。既有配置不会被静默替换。

## 应用内更新

- 更新面板展示实际版本日志、下载进度和安装状态；修复“查看完整更新日志”点击无反应的问题。
- 自动检查默认开启，自动后台下载默认关闭；可继续编辑并关闭面板，后台任务持续进行。
- 下载与签名验证完成后保留安装资源，不自动安装或重启；重复点击检查、下载或安装不会启动重复任务。
- 安装前可保存全部文档，包括未命名草稿；保存取消、外部文件冲突、输入法组合输入、文件操作或会话写入失败时停止安装。
- 增加进程级安装保护与多窗口检查，恢复分栏、活动标签和各窗格 Markdown 模式，并按真实运行版本确认更新结果。

## 文件与兼容修复

- 修复把文件夹拖入窗口时被当作普通文件而报错的问题；文件夹可添加到工作区，混合拖入仍分别处理文件和目录。
- 修复新增光标和更新偏好与桌面设置校验不同步导致的保存失败，保留旧设置及已有配置迁移。

## 下载与更新

- Windows x64：`Markumo_1.0.3_windows_x86_64-setup.exe`。
- Linux x64：`Markumo_1.0.3_linux_x86_64.deb` 或 `Markumo_1.0.3_linux_x86_64.AppImage`。
- macOS Apple Silicon：`Markumo_1.0.3_macos_aarch64.dmg`；Intel：`Markumo_1.0.3_macos_x86_64.dmg`。对应 `.app.tar.gz` 用于应用内更新。

旧版本用户可在应用内检查更新。安装前请保存文档并关闭其他 Markumo 窗口。Linux 的应用内更新适用于 AppImage；DEB 用户请安装新版 DEB。

校验值见 `SHA256SUMS`，更新签名包含在 `latest.json`，不单独提供 `.sig` 附件。Windows 安装包未使用商业代码签名证书；macOS 使用 ad-hoc 签名，未进行 Apple 公证。应用内更新仍执行独立的签名验证。

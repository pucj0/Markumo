# Markumo 1.0.0

轻量桌面文本与 Markdown 编辑器，现提供 Windows、Linux 和 macOS 安装包。

- CodeMirror 文本 / 代码编辑，Markdown Live、源码与双栏预览。
- 工作区、多标签、临时预览、左右分栏与会话恢复。
- 内置图片查看器，支持 PNG、JPEG、GIF、WebP、BMP、SVG、ICO、CUR、AVIF 等格式。
- 内置 PDF 阅读器，默认连续滚动与适应宽度，支持查找、文本选择、旋转及加密文档。
- 新增 GitHub 入口、后台版本检查和签名验证的一键更新。
- 修复空 Markdown 首次编辑时读取 `prefix` 导致的错误。
- 统一 Windows 打包后的安全标签处理，避免安装器因 Low 完整性标签无法覆盖普通安装目录。

## 下载

- Windows x64：`windows_x86_64-setup.exe`
- Linux x64：`.deb` 或 `.AppImage`（应用内更新适用于 AppImage；deb 请安装新版 deb）
- macOS：分别提供 Apple Silicon / Intel 的 `.dmg`，`.app.tar.gz` 用于自动更新。

macOS 使用临时签名，未进行 Apple 公证；首次运行可能需要在系统安全设置中允许打开。Windows 安装包未使用商业代码签名证书，可能显示 SmartScreen 提示。自动更新包另有独立签名，下载后由应用校验。

请先保存所有修改并关闭其他 Markumo 窗口，再安装更新。SHA256SUMS 可用于校验下载文件。

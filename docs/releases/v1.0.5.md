# Markumo 1.0.5

本次更新重点修复正常保存被磁盘检查误拦截的问题，增强未保存内容恢复，并改进 Markdown 工具栏、表格选择和快速打开体验。

## 保存与内容保护

- 后台检查磁盘版本时可以正常手动保存；过期检查结果不会覆盖新保存的版本，也不会制造虚假冲突。
- 临时读取、权限或磁盘占用错误不再被当成持久冲突，失败后可以重试；自动保存采用有限退避，避免重复请求和通知。
- 保留原生内容版本校验。确认外部修改、删除或冲突时继续阻止覆盖，并提供比较差异、另存为、加载磁盘和保留当前编辑内容操作。
- 合并重复文件监测事件，改进焦点检查、多窗口授权及重新加载期间的操作互斥。
- 增强未保存内容的恢复快照、跨进程存储协调与恢复稿保护；重新加载磁盘前确认恢复检查点已持久保存。

## Markdown 编辑

- 新增并改进即时排版格式工具栏，提供标题、行内格式、列表、表格及更多 Markdown 操作，支持窄窗格布局和键盘导航。
- 工具栏状态跟随当前窗格和选区更新；保护代码块与中文输入法组合输入，语言模块加载期间普通文本格式快捷键仍可使用。
- 修复表格内文字选择与单元格选择的切换、单元格文本复制，以及插入链接和图片后的编辑体验。
- 支持末尾块之后继续输入，改进代码块多行粘贴、富文本复制及大文档历史同步。

## 导航与桌面体验

- 改进快速打开的预览标签、固定标签、文件索引刷新及生命周期管理。
- 支持双击 Shift 快速搜索文件，并改进设置、命令和快捷键之间的一致性。
- 改进桌面启动、会话恢复、媒体文件读取和文档转换的安全处理。

## 下载与更新

- Windows x64：`Markumo_1.0.5_windows_x86_64-setup.exe`。
- Linux x64：`Markumo_1.0.5_linux_x86_64.deb` 或 `Markumo_1.0.5_linux_x86_64.AppImage`。
- macOS Apple Silicon：`Markumo_1.0.5_macos_aarch64.dmg`；Intel：`Markumo_1.0.5_macos_x86_64.dmg`。对应 `.app.tar.gz` 用于应用内更新。

旧版本用户可在应用内检查更新。安装前请保存文档并关闭其他 Markumo 窗口。Linux 的应用内更新适用于 AppImage；DEB 用户请安装新版 DEB。

校验值见 `SHA256SUMS`，更新签名包含在 `latest.json`，不单独提供 `.sig` 附件。Windows 安装包未使用商业代码签名证书；macOS 使用 ad-hoc 签名，未进行 Apple 公证。应用内更新仍执行独立的签名验证。

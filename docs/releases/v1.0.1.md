# Markumo 1.0.1

本次更新改进 Markdown 富文本复制、右键菜单与大纲导航。

- 富文本默认复制 Markdown 源码，同时提供 HTML 剪贴板内容；可在「设置 → Markdown → 默认复制行为」切换为可见纯文本。
- 新增「无文字选中时复制或剪切当前整行」设置，默认关闭。
- 富文本右键菜单新增剪切、复制、粘贴、删除图标，复制格式子菜单，格式按钮、标题层级和插入子菜单。
- 支持复制为 Markdown、复制为 HTML 代码、简化格式复制和粘贴为纯文本，以及相应富文本快捷键。
- 点击左右大纲时，将对应标题定位到当前窗格顶部附近；支持富文本、源码、双栏预览及分栏独立滚动。
- 修复富文本长文档后半部分大纲标题遗漏。
- 改进异步剪切、粘贴的选区检查和菜单资源清理。
- 修复分栏布局节点缺少 Vue key 的问题。
- 精简发布附件，不再提供单独的 `.sig` 文件；自动更新验证所需签名已包含在 `latest.json` 中。

## 下载与更新

- Windows x64：`Markumo_1.0.1_windows_x86_64-setup.exe`
- Linux x64：`Markumo_1.0.1_linux_x86_64.deb` 或 `.AppImage`。
- macOS：Apple Silicon 使用 `macos_aarch64.dmg`，Intel 使用 `macos_x86_64.dmg`；`.app.tar.gz` 用于自动更新。

1.0.0 用户可在应用内检查并安装更新。更新前请保存文档并关闭其他 Markumo 窗口。Linux 应用内更新适用于 AppImage；deb 用户请安装新版 deb。下载校验值见 `SHA256SUMS`。

macOS 使用临时签名，未进行 Apple 公证；Windows 安装包未使用商业代码签名证书。它们与应用自动更新的签名验证分别处理。

# Markumo 1.0.4

本次更新改进多语言语法高亮与括号匹配，优化工作区目录树导航，并为 PDF 查看器加入页面缩略图和文档大纲。

## 编辑与语法高亮

- 统一普通代码、Markdown 代码块、即时排版与导出内容的语义配色，提供可切换的语法高亮风格。
- 改进多语言识别和高亮渲染，补充结构化配置文件及嵌入语言的处理。
- 新增“关闭 / 匹配括号 / 彩虹括号”设置，默认启用匹配括号；根据语法区分括号与字符串、注释内容，并限制大文档中的扫描范围。
- 光标动画选项改为直观的平铺样式，便于比较和切换。
- 新配置的默认缩进宽度调整为 4 个空格，已有缩进设置继续保留。

## 工作区与目录树

- 分离目录树选中状态和当前编辑文件，改进预览文件及键盘导航的稳定性。
- 新增单子目录智能展开，默认开启；可选紧凑文件夹显示，将连续的单子目录合并展示。
- 优化目录树虚拟滚动和活动文件定位，改善较大工作区的导航体验。
- 修复智能展开与紧凑文件夹选项无法通过桌面后端校验并保存的问题。

## PDF 阅读

- 新增页面缩略图，可点击跳转，并随当前阅读页更新选中状态。
- 新增文档大纲目录，支持层级展开和跳转到文档内的目标位置。
- 默认显示 PDF 导航侧边栏，支持在缩略图与大纲之间切换。

## 下载与更新

- Windows x64：`Markumo_1.0.4_windows_x86_64-setup.exe`。
- Linux x64：`Markumo_1.0.4_linux_x86_64.deb` 或 `Markumo_1.0.4_linux_x86_64.AppImage`。
- macOS Apple Silicon：`Markumo_1.0.4_macos_aarch64.dmg`；Intel：`Markumo_1.0.4_macos_x86_64.dmg`。对应 `.app.tar.gz` 用于应用内更新。

旧版本用户可在应用内检查更新。安装前请保存文档并关闭其他 Markumo 窗口。Linux 的应用内更新适用于 AppImage；DEB 用户请安装新版 DEB。

校验值见 `SHA256SUMS`，更新签名包含在 `latest.json`，不单独提供 `.sig` 附件。Windows 安装包未使用商业代码签名证书；macOS 使用 ad-hoc 签名，未进行 Apple 公证。应用内更新仍执行独立的签名验证。

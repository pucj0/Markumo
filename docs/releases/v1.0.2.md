# Markumo 1.0.2

本次更新改进大纲面板与 Markdown 阅读、导航体验。

- 右侧大纲宽度支持拖动调整，并自动记忆；双击分隔条恢复默认宽度，也可用方向键微调。
- 点击左右大纲标题时平滑滚动，替代直接跳转；支持富文本、源码和双栏预览。
- 连续点选会从当前位置转向最新标题；滚轮、触摸或键盘操作可中断动画。
- 修正源码模式的最终停靠位置，保持分栏独立滚动，并在切换窗格、关闭编辑器时清理过期动画。
- 窗口变窄时自动限制大纲宽度，为正文保留空间；遵循系统「减少动态效果」设置。
- 调整标题级别标识与大纲层级对齐，避免标识被边缘裁切。
- 表格工具栏按当前编辑的表格显示，切换工具栏时保持正文布局稳定。

## 下载与更新

- Windows x64：`Markumo_1.0.2_windows_x86_64-setup.exe`
- Linux x64：`Markumo_1.0.2_linux_x86_64.deb` 或 `.AppImage`。
- macOS：Apple Silicon 使用 `macos_aarch64.dmg`，Intel 使用 `macos_x86_64.dmg`；`.app.tar.gz` 用于自动更新。

1.0.0 / 1.0.1 用户可在应用内检查并安装更新。请先保存文档并关闭其他 Markumo 窗口。Linux 应用内更新适用于 AppImage；deb 用户请安装新版 deb。

发布页继续不提供单独的 `.sig` 附件，更新签名包含在 `latest.json` 中。下载文件校验值见 `SHA256SUMS`。

macOS 使用临时签名，未进行 Apple 公证；Windows 安装包未使用商业代码签名证书。应用自动更新仍使用独立签名验证。

# Typora 体验复验与修复 — 2026-10-15

范围：基于 `6f9b6709577f` 的既有 Markdown WYSIWYG 专项（通用 Phase 5/6），保留 ProseMirror + CodeMirror 6、Source Preservation 与 DocumentManager 共享历史。状态 **REVIEW**，未达到整体视觉验收门槛，不推进 Phase 7/8，不提交、推送、打包或发布。开始时唯一已有工作树改动 `build.bat` 保留且未编辑。

## 修复与取舍

- Mermaid 首次挂载自动异步渲染 SVG，默认隐藏当前块 CM；只有“编辑图表源码”进入编辑态，完成后自动重绘。搜索/选区导航不再展开源码。语言切入/切出 Mermaid、主题切换、销毁、异步旧结果均受生命周期保护。全局及 flowchart 均关闭 HTML labels，避免净化移除 foreignObject 后图表标签消失。安全级别 strict、SVG 净化、字符/行/边预算保持。
- 行内与独立 `$$` 公式首次挂载自动 KaTeX，点击打开局部公式属性框，应用后自动重绘并支持共享 Undo。没有默认 LaTeX 正文或“点击渲染”按钮。块公式仍用既有 protected_source 存储源码，独立 NodeView 显示，不重写 Schema。普通受保护块与数学块之间切换会重建相应 NodeView。行内数学使用 inline-block 修复点击命中区域。
- 图片属性插件保存 token、精确不可变 Node 引用和位置；每个事务使用 Mapping.mapResult，操作前再次检查 token、节点引用、浮层有效状态。删除、相同节点替换、属性修改或无法可靠映射的全文同步使旧浮层失效；保留的旧按钮回调也不能修改内容。仅前插等不影响目标的事务可跟随位置继续编辑。浮层锚定稳定图片外壳。
- 发现同文档 Pane 独立解析生成不同 sourceId，导致事务同步实际退化为全文替换。新 Pane 复用现有 Pane 的不可变 doc/blocks 快照（各自桥接实例），后续可重放真实 PM steps，保持图片目标映射、独立选区与搜索状态。这是本次多 Pane 缺陷修复，不是全量重构。
- Live Search 将连续文本按非文本节点分段，允许跨 marks，禁止匹配穿过图片、数学、软/硬换行、不同段落或表格单元格。代码块内的文本/换行可按正则搜索。替换按原 mark run 字符长度分配新文本，保留链接 URL 与格式边界，不把首个 mark 扩散到整个匹配。正则替换使用原始匹配上下文，支持 `$1`、命名捕获、lookaround、`$$`、`$&`、前后文替换；修复 Unicode 零长度推进及全词分支优先级。
- 替换始终通过 PM Transaction 和 canonical 文档历史；跨 Pane 变更后重算匹配再替换。修复修改块时 CRLF 边界中的孤立 CR 丢失：解析时完整保留换行到 prefix，序列化多行块沿用该块 CRLF。未修改块仍取原始 raw。
- 搜索高亮最多 1500 处。达到上限时“全部替换”明确拒绝并提示缩小范围，不再静默仅替换前 1500 处；普通替换仍可逐项操作。零长度正则匹配不提供插入式替换。修改子树可能规范化其 Markdown 语法，不能承诺被修改段落内所有引用式/自动链接写法逐字节不变；URL、marks、未修改块和普通单元格保真有定向测试。

## 可移植测试入口

`playwright@1.64.1` 作为锁定的项目 devDependency，只用于测试，不进入应用发行包。四个 Markdown 驱动移除私人目录和环境包路径 fallback，直接解析项目依赖。`pnpm test:ui:markdown` 自动在项目根创建随机回环端口 Vite 服务、依次跑组件/Typora/性能驱动并 finally 关闭服务；无需预先开固定 1422/1423 端口。Windows 默认使用安装的 Edge；其他平台默认 Playwright Chromium（先运行 `pnpm exec playwright install chromium`），可用 `LIGHTEDIT_BROWSER_CHANNEL` 选择已安装通道。原生测试仍单独运行，检测已有 LightEdit 窗口后拒绝启动，保护用户未保存文件。

## 人工验收与后续依赖

1. 在 Windows 打开 fixture，首次等待后确认 SVG/公式已显示；点击图表源码才出现 CM，完成恢复图表；点击行内/块公式编辑并撤销，源码无额外改动。
2. 两 Pane 打开同一文档，主 Pane 打开图片浮层；副 Pane 在前面编辑，主 Pane 应仍能改正确图片。副 Pane 删除/更换该图片后主浮层必须关闭，不能修改相邻图片。
3. Live 内 Ctrl+R 替换跨粗体/链接、表格中文、代码正则捕获，确认 URL/表格定界符、未修改块和 Undo；始终 Live。1500 上限应收到明确拒绝提示。
4. 补齐 Typora 窗口读取授权后，在 Typora 实际打开同一 fixture，记录主题/字体/字号/缩放/窗口尺寸，统一设置后重新截图，逐项记录差异；不得把现有 UNVERIFIED 改成 PASS。

剩余风险：复杂回溯 JS 正则仍在主线程，无硬超时；1500 上限下批量替换受限；真实 IME/DPI/大尺寸图片与长时性能仍待验。公式局部编辑在“应用”时更新，未提供键入时的实时预览。整体完成门槛未达到，保持 REVIEW，等待本专项评审及缺项补验。

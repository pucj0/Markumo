- GitHub 仓库已由 `pucj0/lightEdit` 更名为 [pucj0/Markumo](https://github.com/pucj0/Markumo)。仓库 ID `1416691133` 保持一致；默认分支 `main` 与公开状态不变。通过仓库 ID 重新查询 canonical 名称，并用 `git ls-remote --heads origin` 验证新地址可访问。

- 标题栏、欢迎页、网页标题、默认键位方案的显示名称、诊断日志与演示文档改用 Markumo。

## 兼容性

- 保留 Tauri 标识 `com.lightedit.app`、默认开发数据目录 `.lightedit-dev/`、浏览器设置键 `lightedit.settings.v1`、键位方案 ID `lightedit`。更名后继续读取原设置、最近文件与会话元数据，不为品牌更名搬迁或删除用户数据。

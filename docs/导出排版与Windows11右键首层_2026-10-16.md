# 导出排版与 Windows 11 右键首层（2026-10-16）

## 菜单与导出

- 文件菜单中的导入、导出相邻，菜单最小宽度增至 232px；格式名称去掉省略号。
- 静态 HTML、PDF、PNG 不包含复制按钮。代码等待语言支持加载后高亮，使用编辑器共用的语法颜色；行号由 CSS 生成，不混入可复制的代码文本。
- 导出读取当前 Markdown 字体、正文宽度和主题颜色。PNG 在独立 iframe 中渲染完整文档后截图，等待字体和图片加载。
- 无主题 HTML 不添加展示行号。Word 仍走原有 Pandoc 转换，未声称与浏览器排版逐像素一致。

## 原生右键入口

`src-tauri/windows/shell/MarkumoShell.cpp` 实现 IExplorerCommand；稀疏 MSIX 声明 COM 服务器和 `windows.fileExplorerContextMenus`，供 Windows 11 首层菜单使用。普通注册表入口仅作经典菜单兼容路径，不能代替首层验收。

命令只读取本地文件路径，明确指定 markumo.exe 启动，无命令解释器；支持中文、空格、多选和 Windows 参数转义。卸载/更新只移除本安装目录记录的包，先注销再覆盖 DLL。

构建入口：`node scripts/tauri.mjs build --bundles nsis`。需要 Visual Studio C++ 工具和 Windows SDK。仅重新打包可用 `node scripts/tauri.mjs bundle --bundles nsis`。

正式分发需受信任的代码签名证书，通过 `MARKUMO_SHELL_CERTIFICATE_PFX` 与 `MARKUMO_SHELL_CERTIFICATE_PASSWORD` 提供。安装器不自动导入证书或修改开发者模式。未签名包含可执行激活的包会被 Windows 拒绝。

按用户后续要求，安装时若证书校验或新版右键注册失败，仅写安装详情日志，不弹窗、不阻断安装，保留经典右键入口；不能将静默失败记为首层菜单安装成功。

本机开发签名用 `scripts/prepare-local-shell-signing.ps1`；私钥以当前用户 DPAPI 加密保存在忽略的 target 目录，临时 PFX 签名后删除，不进入安装包。公开证书和私钥不可混为一谈。

实测 CurrentUser\TrustedPeople 导入后仍报 0x800B0109。[微软故障排除文档](https://learn.microsoft.com/en-us/windows/msix/msix-troubleshooting-guide) 要求 LocalMachine\TrustedPeople。该步骤须用户明确授权和管理员确认，不向 Root 导入。

本次公开证书：CN=Markumo Local Development，指纹 `9A5FA84272A3D6F2D4FF5253AB3C50B94BF4774F`，有效至 2027-10-16。用户分别批准了当前用户与本地计算机 TrustedPeople 导入。开发证书只适合本地验收，不是公开发布签名。

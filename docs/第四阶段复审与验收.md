## 发现并修复的缺陷

1. **重命名后保存失效**：原代码在旧路径已消失后再 canonicalize，未更新文件 token 授权。先保存规范化旧路径、串行锁定服务，更新文件/目录后代授权和最近文件路径；前端同步 Tab/path/URI，保留选区、文本、dirty 与撤销历史。
2. **移动功能未接到 UI**：增加移动入口、目标目录输入和明确确认；目录子文件同步路径与授权，移动后可继续 Ctrl+S。
3. **确认被跳过**：原代码把 Tauri 注入的异步 `confirm()` 当同步布尔值，既可能跳过确认，也触发权限异常。替换为应用内异步确认对话框；取消不调用修改接口。新建/重命名也改为应用内输入，支持 Esc、Tab 和 IME 保护。
4. **搜索取消后继续收旧结果**：取消立即清空活动 id，切换工作区和销毁时取消，生成带序号的 id；丢弃过期批次/错误/快速打开响应，取消前的已显示结果可保留。后端完成事件真实报告 canceled，并防同 id 的旧任务清理新 token。
5. **Unicode 定位错误与伪分批**：原列号为 UTF-8 字节偏移，单个文件内也可能累计一大批。现按 CodeMirror 的 UTF-16 列号定位，每 32 条立即发送；匹配次数上限 1000，预览文本截断到 1024 字符，限制文件读取大小；支持 UTF-8/BOM、UTF-16 BOM 与 CR/LF/CRLF。
6. **快速打开只查已展开目录**：增加按用户查询异步枚举文件名，覆盖未展开目录，支持模糊子序列匹配、过期响应丢弃与 100 个候选上限。目录树初次打开仍只读一层；面板关闭时不在每次编辑中遍历全部工作区候选。
7. **忽略规则错误且无覆盖入口**：使用 Rust `ignore` 的 Gitignore 匹配，支持精确名称、否定、根锚定和嵌套规则；增加显示被忽略文件开关，树/搜索/快速打开共用规则。
8. **文件安全缺口**：校验单个文件名，拒绝路径跳转、ADS、设备名、链接和 Windows junction；拒绝根目录移动与移入自身，创建使用 create_new 防同名覆盖，Windows 移动使用不带 REPLACE_EXISTING 的 MoveFileExW 防外部竞争创建目标时覆盖。删除前阻止存在已打开后代的条目，编辑内容保留；文件操作期间阻止保存竞态。
9. **状态/UI/生命周期**：工作区控制器通过 Vue reactive 接入，订阅在代理建立后注册；修复异步注册后销毁时漏解绑、加载失败后 loading 不清理、空文件夹重复并发加载、创建子文件漏掉未加载兄弟、根目录读取失败后状态部分切换。树增加虚拟滚动，每次最多渲染 30 行；修复搜索聚焦和窄窗口中 CSS 永久隐藏侧栏的问题，重开侧栏恢复已有查询。单击 preview、双击 pin，并释放被替换 preview 的 token；IME 在打开过程中开始时也释放迟到的新 token，保留旧授权。
10. **历史持久化**：工作区最近历史独立存储，用临时文件持久化替换；失败明确提示，不静默宣称已写入；失败打开保留原根目录。

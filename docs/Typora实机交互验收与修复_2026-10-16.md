## 源码与测试边界

继续使用 ProseMirror 正文、CodeMirror 6 普通文件/Source/Split/围栏代码。行内编辑只替换当前语法范围的编辑 DOM；语义仍经 PM Transaction，raw patch 在桥接层验证对应同一块后进入 DocumentManager 历史，不从任意 DOM HTML 反推全文。位置跨文档修改由 Transaction Mapping 与 source patch 同步；超预算/多段落 raw 草稿保留并阻止不安全模式切换，Esc 取消未应用部分。

图片属性按钮继续验证 token、映射后位置和精确 Node 引用；本轮没有用“重新查找相同 src”替代身份校验。Live Search 保留正在协作修改中的共用搜索实现；跨 Mark、代码、中文、捕获组、多 Pane、URL、表格、未改 Markdown、共享 Undo 回归通过。1500 匹配预算达到时明确拒绝 Replace All；跨图片/原子节点不匹配。复杂正则没有硬中止沙箱，未宣称任意大文档/恶意表达式都低延迟。

当前实测性能（本机浏览器样本）：102400 字符中文文档 Live 查找 **27.7ms**，1500 匹配上限；活动查找期间输入 p95 **9.2ms**，保持 Live 和同一编辑 DOM。100KB 打开约 140ms、事务 p95 4.7ms；1.2M 字符仍按既有阈值降为 Source，原文保留。这些是样本，不是所有硬件的 SLA。

## 本轮文件用途

- `src/editor/markdown/wysiwyg/InlineSourceView.ts`：原位原生文本编辑、标记样式、原位光标、精确补丁、中文 composition、快捷键路由、位置/旧界面失效保护。
- `MarkdownEditorController.ts`：正文/行内选择与结构命令、显式属性入口、公式实时局部预览、YAML/TOC 阅读态。
- `LiveImageView.ts`：图片属性请求携带真实 Node/getPos；避免 pointer-down 先收起源码导致点击错位。
- `CodeBlockView.ts`：保留 Mermaid 预览、编辑失焦、异步渲染世代与防抖。
- `LanguageSelector.ts`：视口定位、浮动候选与滚动同步；不推开正文。
- `MarkdownTheme.css`：行内原位样式、30px 页面内边距、标题/段落/列表/表格/TOC/代码控件排版与浅色正文颜色。
- `contracts.ts`、`src-tauri/src/commands/settings.rs`：新默认行高一致为 1.6，已有显式用户偏好不迁移覆盖。
- `tests/markdown-wysiwyg-ui.mjs`、`tests/typora-parity-ui.mjs`、`tests/language-experience-ui.mjs`、`tests/language-experience-native.mjs`：更新真实交互契约并增加字形、快捷键、YAML/TOC 和原生保存回归。
- `tests/typora-visual-ui.mjs`、`tests/run-markdown.mjs`：可复跑同窗口尺寸截图与统一入口；字体/主题差异明确记录。
- 本报告、差距矩阵、架构说明与阶段台账：将实机观察、修复、剩余差异和证据分开记录；历史报告不重写。
